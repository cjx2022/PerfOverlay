## 对比 v0.9.8

### 新增：控制面板标题栏图标

设置面板左上角、产品名左侧显示程序图标，与标题文字同高。固定使用蓝底白折线那一套，
浅色与深色主题下一致；与托盘、exe 文件图标同一份资源。

### 增强：采集目标显示实时进程

设置 → 帧数采集 里显示当前正在采集的进程名与 PID，前台切换窗口即随之变化；
没有锁定目标时直接写明「未锁定（等前台窗口出帧）」。原「采集通道」一行移除。

### 精简：设置面板

- 移除行为面板底部「关闭本窗口不退出程序」提示。
- 移除帧数采集说明中的「开机自启时会弹授权框，点『是』即可」。
- 热键输入框宽度改为与上方「左上 / 中上 / 右上」按钮组两端对齐。
- 「显示项目」标题移到卡片内左上，与其余三张卡的标题落在同一水平线上。
- 面板高度 576 → 537 DIP。

### 统一：字体与菜单高亮

- 全程序统一使用微软雅黑（原先浮窗的文字排版优先取 Segoe UI，同一行里中西文混排）。
- 托盘菜单的悬停高亮铺满整行，不再只包住文字周围的一小块。

版本号进入 1.0.0。
