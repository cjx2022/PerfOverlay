## v1.0.1

**浮窗可拖到任务栏上**

位置基线改为整块屏幕，可一路贴到屏幕最底、覆盖在任务栏之上。保留 24 DIP 可抓取区域，重启后位置保持。

**被遮挡时自动抢回最上层**

按真实窗口层级判定遮挡。任务栏、置顶工具或全屏应用压住浮窗时自动恢复置顶，全程不抢焦点、不打断当前操作。

**不支持独占全屏**

本程序为非注入式，不使用任何进程注入与画面挂钩。独占全屏（游戏内选「全屏」并开启独占模式）下系统不合成叠加窗口，浮窗无法显示；请使用「无边框窗口 / 窗口化全屏」，画面与延迟一致。

## 文件

```

SHA256  95351db6d62f55582a132c77536cbe82319de00b57886c52b3448e4ce67ece22
```

安装前先在托盘右键退出正在运行的旧版本（常驻单实例，旧进程不退会让新版本静默退出）。
