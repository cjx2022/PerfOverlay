## 新增

- **新图标**：蓝底 / 黑底 + 白色上行折线（左下到右上），浅色任务栏用蓝底、深色任务栏用黑底。小尺寸单独调过线宽与折点，16px 任务栏下也读得出是折线。
- **托盘图标跟随任务栏配色**：跟系统「Windows 模式」走，在系统里改一下立刻生效，不用重启。
- **显示延迟**：Present 调用到画面出屏的毫秒数（中位数），悬停可看 P95 与样本数。**默认关闭**，自己勾。
- 只对游戏有效：浏览器（含网页视频）、Electron、窗口化播放走 DirectComposition，整段取不到出屏时刻，显示 `--`。选项右边加了 ① 图标说明这件事，并给出体感参考（≤8ms 无感 / 8–17ms 顺畅 / 17–33ms 发钝 / >50ms 卡）。
- 取数走 PresentMon 的 ETW 事件，不依赖显卡厂商，NVIDIA / AMD / Intel 通用。

## 注意

- 这是**出屏延迟**，不是输入延迟。端到端延迟（点到屏幕亮）纯软件测不出来，别拿它对 Reflex 的数。
- 延迟与帧数共用同一条采集链路：帧数 N/A 时，延迟也拿不到。
- 旧配置升级后延迟保持关闭，托盘图标按当前任务栏配色自动选。
